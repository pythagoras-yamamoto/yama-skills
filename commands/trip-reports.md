# 山行記録の収集

日本の山について、ヤマレコと YAMAP から最近の山行記録を集め、登山道の状況・装備・危険箇所を要約します。

引数で山名が渡された場合（例: `/yama:trip-reports 谷川岳`、`/yama:trip-reports 谷川岳 西黒尾根`）はそれを対象にします。無ければどの山か聞いてください。

## 1. 山の特定

```bash
cd ${CLAUDE_PLUGIN_ROOT}/skills/yama-route-researcher/tools && uv run python find_peak.py "{山名}"
```

候補が複数なら AskUserQuestion で選んでもらう（「{山名}（{標高}m、{都道府県}）- {地理院地図リンク}」）。

## 2. 記録を集める（並列）

URL を推測せず、検索で見つけた URL だけを WebFetch する。失敗したら `uv run python ${CLAUDE_PLUGIN_ROOT}/skills/yama-route-researcher/tools/cloudscrape.py "{url}"`、さらに `--render`。

### ヤマレコ

1. `WebSearch "{山名} {ルート名} site:yamareco.com/modules/yamareco/detail"`
2. 直近の記録を中心に最大8件を読む

### YAMAP

1. `WebSearch "{山名} site:yamap.com/activities"`
2. 最大5件を読む

### 各記録から抜き出す

日付、投稿者、山行形態、コース、実際のタイム、天気、登山道の状況（残雪・凍結・ぬかるみ・崩落）、装備、危険箇所（落石・滑落・道迷い・熊）、水場、山小屋の混雑、駐車場の様子

### 取れなかったとき

- 片方しか取れなければ、もう片方で続ける
- 両方駄目なら、記録が見つからなかったと伝え、山小屋の公式ブログ・自治体の登山道情報を探すよう勧める

## 3. 結果の表示

1. **山:** 名前、標高、都道府県
2. **概要:** 「{X}件の記録（{情報源}、{期間}）」
3. **記録（新しい順）:** 各記録について
   - **日付** | **投稿者** | **情報源** | **山行形態**
   - **コース:**
   - **状況:**
   - **要点:** 1〜2文
   - **リンク:** 記録の URL
4. **共通点**（3件以上あれば）: 多くの記録が一致する状況、繰り返し出てくる危険、よく挙がる装備
5. **注意:** 情報源が欠けた、記録が古い（6か月以上前ばかり）、季節が違う、など
